# Deploying the Hub to Laravel Cloud

For hosts that can't run the Hub (e.g. Managed WordPress platforms),
[Laravel Cloud](https://cloud.laravel.com) is the zero-maintenance option:
it builds and deploys straight from GitHub, includes the database, HTTPS,
and the task scheduler, and there is no server to look after. Expect roughly
$20/month for a small production app (a free sandbox tier exists for trying
it out, but sandboxes sleep — use a production environment for real use).

## 1 · Sign up and connect the repo

1. Go to cloud.laravel.com → **Sign in with GitHub** (use the account that
   owns this repo).
2. **Create application** → pick this repository and the branch to deploy.
3. Choose the region closest to the UK (EU region).

## 2 · Add a database

In the application's **Resources**, add a database. Laravel Cloud injects
the connection details automatically — no `.env` editing needed for the DB.

## 3 · Environment settings

In **Environment → Variables**, set:

```ini
APP_NAME="Areterra Hub"
APP_URL=https://hub.areterra.co.uk   # or the *.laravel.cloud URL until DNS is set

MAIL_MAILER=smtp
MAIL_HOST=smtp.office365.com
MAIL_PORT=587
MAIL_USERNAME=team@areterra.co.uk
MAIL_PASSWORD=<mailbox or app password>
MAIL_FROM_ADDRESS=team@areterra.co.uk
MAIL_FROM_NAME="Areterra Team"

VAPID_PUBLIC_KEY=<see below>
VAPID_PRIVATE_KEY=<see below>
```

`APP_KEY` is generated by the platform. For the VAPID keys, run
`php artisan webpush:vapid --show` anywhere (or use the platform's command
runner after first deploy) and paste the two values.

## 4 · Build & deploy settings

The defaults work: Laravel Cloud runs `composer install`, `npm ci && npm
run build`, and caches config/routes. Two things to switch on:

- **Deploy commands**: add `php artisan migrate --force` so releases run
  migrations. For the very first deploy use
  `php artisan migrate --seed --force` once (then remove `--seed`).
- **Scheduler**: enable the scheduler for the environment — this powers the
  12:00 register and 14:30 end-of-day reminders.

Press **Deploy**. The app is live on its `*.laravel.cloud` URL.

## 5 · Custom domain

In the application's **Domains**, add `hub.areterra.co.uk`. It shows a
CNAME record — add that record in whatever panel manages DNS for
areterra.co.uk (your hosting provider's DNS/domain section; a Managed
WordPress platform still lets you add DNS records for subdomains, it just
won't *host* them). HTTPS is automatic once DNS resolves.

## 6 · First login

Log in as `ekilburn@areterra.co.uk` / `password`, go to **My Account**, and
change the password immediately — then do the same for the other seeded
accounts. Check the platform's automatic database backups are enabled.

## Updating later

Push to the deploy branch (or click Deploy). Nothing else — builds,
migrations, and cache refresh all run automatically.
